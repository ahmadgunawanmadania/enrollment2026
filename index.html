database

Sinkronisasi Data Lama

Gunakan tombol ini untuk menyalin semua data historis dari Google Sheets ke database Firebase. Proses ini hanya perlu dijalankan satu kali. Ini mungkin memakan waktu beberapa menit tergantung pada jumlah data.

PENTING: Pastikan tidak ada yang menginput data baru saat proses ini berjalan untuk menghindari konflik.

upload

Upload Data Massal

Gunakan tombol ini untuk meng-upload semua data dari sheet Siswa_Lanjutan ke database Firebase. Ini akan menimpa data yang ada dan memastikan daftar siswa untuk form "Continuing Students" selalu ter-update.
